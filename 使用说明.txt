鼠标桌面手势 1.5.1 — Windows 10 / 11 x64 免安装版

开始使用
解压整个文件夹，运行 MouseDesktopGestures.exe；不需要安装 AutoHotkey。
双击右下角托盘图标打开设置。请勿同时运行旧版程序或脚本。
默认左右手势沿用旧版方向，上滑打开任务视图，短按保留后退／前进。

方向锁定与防抖
位移超过阈值且主方向明显占优，持续稳定 40 毫秒后才锁定方向。
默认优势比例为 135%，即主方向位移至少是另一方向的 1.35 倍。
锁定后，继续斜向移动不会改变动作。回到起点附近松开可以取消。
为避免边界抖动，已锁定方向松开时的位移需大于阈值的 65%。
明显对角线、移动后返回起点、长按但没有有效手势，不触发点击。
连续动作默认至少间隔 180 毫秒；这个间隔不影响短按。
在“常规设置”中可调整阈值、锁定时间、优势比例和动作间隔。
若快速甩动不易触发，可降低方向稳定时间，设为 0 可立即锁定。

鼠标按键检测
从托盘菜单或设置窗口进入“鼠标按键检测”。
窗口显示左右键、中键、XButton1、XButton2 和滚轮的名称、按下／松开事件。
检测期间手势停用，鼠标事件原样传给应用；最多显示最近 100 条。
点击结束检测或关闭窗口恢复原状态，60 秒后也会自动结束。
如果厂商软件把侧键映射成键盘按键，本检测不会把它认成侧键；
请先在厂商软件中恢复鼠标后退／前进映射。

Debug 日志
默认关闭，可在设置或托盘菜单中开启。
日志位于 logs\debug.log，记录启动、前台进程、手势开始／结束、方向锁定、
相对位移、触发动作、取消、防抖和按键检测事件。
不记录键盘输入、窗口标题或屏幕内容。
超过约 1 MB 后移至 debug.log.1，只保留当前日志和一份轮换日志。
“打开日志目录”可直接找到文件；关闭 Debug 后停止新增日志。

JSON 配置与旧版本升级
config.json 位于程序旁边，GUI 保存后立即生效，重启后自动读取。
保存时上一份 JSON 备份为 config.json.bak；手工修改后需重启。
如果 JSON 损坏，程序提示并暂用默认设置，原文件不自动覆盖。
修正 JSON 或在设置中保存后恢复；保存仍会备份原文件。
从 1.1 升级时：退出旧程序，把新版 EXE、source、licenses 和说明文件复制过去。
如果旧目录还没有 config.json，不要先复制分享包里的默认 JSON，
让新版首次启动自动读取旧 config.ini 并生成 JSON。原 INI 保留。
JSON 存在时优先读取 JSON，不再读取 INI。
分享包使用默认配置，你电脑升级时的私人设置不在分享包里。

应用白名单（前台时禁用手势）
在“应用白名单”中填写进程名（例如 game.exe），或选择应用的 EXE。
也可先切到目标应用，回到设置后点击“添加上一个应用”。
点击“保存并应用”后生效。名单默认为空，最多支持 100 个应用。
这些应用在前台时，手势自动禁用；侧键直接执行原始按下／松开功能。
切到其他应用后立即恢复，托盘图标的提示文字会显示当前禁用状态。
按进程名匹配，不区分大小写。添加的是实际窗口进程，
如果游戏启动器和游戏本体名称不同，请添加游戏本体的进程名。
该名单只看当前前台窗口，不是“某程序只要在后台运行就全局禁用”。
本版没有为不同应用分别配置动作。

其他功能
两个侧键可分别启用，并分别设置四个方向动作。
默认短按时限 350 毫秒，整个移动过程未超过阈值时，发送原侧键点击。
暂停或禁用侧键后，侧键原始事件直接传给应用。
一次使用一个侧键，同时按两个侧键会取消手势。
切换桌面需先按 Win+Tab 创建至少两个虚拟桌面。
开机启动使用当前用户启动文件夹中的 MouseDesktopGestures.lnk。
默认关闭；移动程序后请关闭再开启；删除程序前请先关闭。

程序不需要联网。本版未进行代码签名。
包内含源代码、构建说明和运行引擎许可证。

1.3 新增：配置导入、导出与恢复
设置窗口新增“配置管理”页。
导入配置：选择 JSON 文件，先载入界面；检查后点击“保存并应用”才生效。
取消设置窗口会放弃导入的预览，原本正在使用的配置不变。
导出配置：导出当前界面的设置，即使尚未保存；不会应用或改变本机配置。
恢复上一份设置：读取 config.json.bak，先载入界面预览，再保存应用。
没有备份时按钮不可用。恢复并保存后，恢复前的设置仍会成为新的备份。
分享内容包含手势、灵敏度、防抖、Debug 开关、静默模式和应用白名单，
不包含开机启动、程序路径或日志内容。导入与恢复保留本机开机启动选择。
无效 JSON、超出范围的参数、未知动作或不支持的配置版本会拒绝导入，
现有设置不会因为导入失败而改变。
导出请另选文件，不要覆盖程序正在使用的 config.json 或其备份。

1.3 新增：独立图标与关于窗口
使用 AI 生成的蓝底鼠标与双向箭头图标，已嵌入 EXE 与托盘。
ICO 包含 16、24、32、48、64、128、256 像素尺寸。
“关于”可从托盘菜单或设置左侧的“关于这个应用”打开，显示版本及运行环境信息。
assets 中保留图标原图、ICO 和生成提示词。
单独运行 EXE 不依赖外部图标文件。
1.4 新增：界面优化
浅色卡片与左侧导航，统一字体、间距和按钮样式。
常规设置、侧键手势、应用白名单、配置管理分别显示。
顶部显示当前手势状态及前台应用，蓝色主按钮保存并应用。
按键检测与关于窗口采用统一视觉样式，检测页显示最近事件数量。
配置格式和手势功能保持兼容；升级时保留原 config.json 与备份。


1.4.1 改进：大尺寸开关
六个设置选项改为整块可点击的开关，蓝色表示已开启，灰色表示已关闭。
同时显示状态文字，可用 Tab 定位后按空格切换。
点击开关只修改界面草稿，仍需点击保存并应用。

1.5.1 新增：静默模式
在常规设置中开启静默模式并保存后，托盘图标会立即隐藏，手势继续运行。
登录 Windows 后，开机启动快捷方式通过 --startup 参数在后台启动，不弹出设置窗口。
再次双击同一路径的 MouseDesktopGestures.exe，会打开现有进程的设置窗口，不会产生第二个常驻进程。
设置窗口提供“暂停手势”和“退出程序”，隐藏托盘时仍可管理。
关闭静默模式并保存后，托盘图标会重新显示。
静默模式不会隐藏 Windows 任务管理器中的进程。
已启用开机启动的旧版用户首次运行时，程序会将指向当前 EXE 的旧快捷方式更新为 --startup。
移动 EXE 后需重新设置开机启动；其他来源的快捷方式不会被改写。
