MouseDesktopGestures 1.5.2

构建环境：Windows 10/11 x64，PowerShell 7。
固定运行引擎：官方 AutoHotkey 2.0.28 x64。
固定编译器：官方 Ahk2Exe 1.1.37.02a2，不压缩。
应用源代码：GPL-2.0-or-later，见根目录 LICENSE。
运行引擎许可证：../licenses/AutoHotkey-GPL-2.0.txt。
运行引擎源码归档：AutoHotkey-v2.0.28-source.zip。

从仓库根目录构建、运行内置自检并更新仓库 EXE：
pwsh ./scripts/build.ps1 -UpdateTrackedExe

额外执行 30 次单实例并发启动验证并生成发布 ZIP、SHA256SUMS：
pwsh ./scripts/build.ps1 -UpdateTrackedExe -InstanceStress -Package

脚本从官方 GitHub Release 下载上述固定工具版本到 .tools/，先验证 SHA-256，
再编译到 dist/。它会检查 VERSION 与源码、说明、EXE 的版本一致性，
运行 EXE --self-test，验证通过后才更新根目录 EXE。
发布打包只从脚本中的固定文件清单复制：仓库的 config.default.json 在 ZIP 中命名为
config.json；仓库目录中运行产生的个人 config.json，以及临时加入源码或素材目录的文件，
都不会进入 ZIP。发布前仍须检查 Git 暂存内容是否含个人文件。
dist/ 和 .tools/ 已被 Git 忽略。自检产生的临时文件留在 dist/ 供排错。

直接运行自检：
MouseDesktopGestures.exe --self-test C:\path\to\scratch

自检覆盖 JSON、配置损坏隔离与备份保留、INI 迁移、方向锁定、白名单、
设置草稿、导入导出、按键检测、日志轮换、开机启动快捷方式健康检查。
退出码 0 表示通过。--self-test 只使用指定的 scratch 目录，
不会更改真实 Windows 开机启动快捷方式。

启动参数：--settings 打开设置；--detect 打开鼠标按键检测；
--about 打开关于；--startup 静默登录启动。

源码 .ahk 文件须保存为带 BOM 的 UTF-8 编码，以正确编译中文文本。
Json.ahk 与 UiTheme.ahk 会编入 EXE；运行时不依赖外部 AHK 文件。
图标来自 ../assets/app.ico，编译时须保持相对路径。
